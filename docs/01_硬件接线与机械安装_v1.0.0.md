# 01 · 硬件接线与机械安装

> 这一步错了后面全是玄学。**接完先别上电，对着文末检查清单过一遍。**
> 全程断电接线，插拔杜邦线时不要带电。

---

## 引脚表（照这张表接，一个都不能错）

### ESP32 侧

| 功能 | ESP32 引脚 | 说明 |
|---|---|---|
| 左电机 IN1 | GPIO2 | DRV8837 左通道（代码 `L_IN1`） |
| 左电机 IN2 | GPIO4 | 同左通道（代码 `L_IN2`） |
| 右电机 IN1 | GPIO13 | DRV8837 右通道（代码 `R_IN1`） |
| 右电机 IN2 | GPIO27 | 同右通道（代码 `R_IN2`） |
| 激光 前 XSHUT | GPIO18 | 上电后改地址为 0x30 |
| 激光 后 XSHUT | GPIO23 | → 0x31 |
| 激光 左 XSHUT | GPIO5 | → 0x32 |
| 激光 右 XSHUT | GPIO19 | → 0x33 |
| I2C SDA | GPIO22 | 四路激光 + 板载 MPU6050 共用 |
| I2C SCL | GPIO21 | 同上 |
| 串口 RX | GPIO32 | **接 RDK 的 TX** |
| 串口 TX | GPIO33 | **接 RDK 的 RX** |
| GND | GND | **必须和 RDK 共地** |

> 左电机是 `GPIO2 / GPIO4`，右电机是 `GPIO13 / GPIO27`；上表顺序按 DRV8837 的 IN1–IN4 写，
> 按你板上丝印对应的两个脚接即可，**同一电机两根线接同一通道**。

### 四路 VL53L0X 公共线

| 模块引脚 | 接到 |
|---|---|
| VIN | **3.3V**（接 5V 会烧模块） |
| GND | GND |
| SDA | 四路全部并联到 GPIO22 |
| SCL | 四路全部并联到 GPIO21 |
| XSHUT | 各自独立接上表对应的 GPIO |
| GPIO1 / INT | 不接 |

### RDK 侧串口

| RDK | 接到 ESP32 |
|---|---|
| TX（发） | GPIO32（ESP32 的 RX） |
| RX（收） | GPIO33（ESP32 的 TX） |
| GND | GND |

> 交叉接线是唯一正确接法：**发对收、收对发**。接成 TX→TX 会出现「能发不能收」。

## 为什么四路激光能同时用

VL53L0X 出厂地址都是 `0x29`，四个模块直接并联会地址冲突，谁都读不到。

解决办法是给每个模块一根 **XSHUT**（关断脚）：主控先把四路 XSHUT 全部拉低（四个模块都睡死），
然后一次只拉高一个，给它改成新地址，再拉高下一个。最终地址：

```
前 0x30   后 0x31   左 0x32   右 0x33
```

这段逻辑已经写在固件 `vlInit()` 里，**你只要保证四根 XSHUT 各自独立、别接错、别悬空**。
XSHUT 悬空时模块会一直醒着，四个 0x29 打架，开机就报 `VL F FAIL`。

## 机械安装（这步决定成败）

### 1. 传感器朝向

四个模块分别朝车头、车尾、车身左侧、车身右侧，镜头**水平向外**，不要有明显的俯角或仰角。

### 2. 一定要把镜头侧垫高 2–3mm

这是本项目踩得最惨的坑，务必照做：

**现象**：传感器微朝下（哪怕只有 11° 左右），转一圈测出来的距离全是 200–250mm，
或者前、后两路一直是 `-1`、左右两路恒定 240mm 左右不动。

**原因**：VL53L0X 返回的是「视野内最近的物体」。镜头有俯角时，地面就在视野里，
距离只有 250mm 左右，比墙近得多，于是它永远报地面，墙面数据被彻底挡住。

**做法**：在传感器模块**镜头那一侧的底部**垫 2–3mm（纸片、垫片、小螺丝都行），
让镜头**微微向上仰**一点点。仰角不用大，肉眼几乎看不出来就行。

**验证**：改完后同一位置读数应该从 200–250 变成 **500–1000mm** 之间。
如果还是 200 多，说明垫的方向反了（垫到了背侧）或垫得不够。

### 3. 车轮与遮挡

- 车轮、底盘、走线不要挡在传感器镜头正前方 20cm 内
- 线束用扎带固定，避免转动时甩到镜头前面

## 上电自检顺序

1. **先不接电机电源**，只给 ESP32 和 RDK 上电
2. 用电脑串口或 RDK 看开机输出，应该依次出现：
   ```
   BUS[all_off]: 68
   BUS[F_on]: 29 68
   VL F OK
   VL B OK
   VL L OK
   VL R OK
   BUS[final]: 30 31 32 33 68
   GYRO: 0x68 r75=68 r00=85 r0F=B0
   MPU: bias=xxx n=200
   READY
   ```
3. 上面 4 个 `VL x OK` **必须全 OK**。有 `FAIL` 的，先回去查那一路的 XSHUT 和 SDA/SCL
4. 全部 OK 之后，再给电机供电，把车架起来（轮子悬空）测转向

> `BUS[all_off]: 68` 里的 `68` 是板载 MPU6050，正常。
> `final` 那行能看到 `30 31 32 33 68` 五个地址，说明四路都改成功、陀螺也在线。

## 检查清单（接完对照打勾）

- [ ] 左电机两根线 → GPIO2 / GPIO4 同一通道
- [ ] 右电机两根线 → GPIO13 / GPIO27 同一通道
- [ ] 四路 VIN 全部 3.3V
- [ ] 四路 SDA 全部 GPIO22、SCL 全部 GPIO21（并联，不是串接）
- [ ] 四路 XSHUT 分别 18 / 23 / 5 / 19，无悬空
- [ ] ESP32 GPIO32 ← RDK TX；ESP32 GPIO33 → RDK RX
- [ ] ESP32 GND 与 RDK GND 相连
- [ ] 镜头侧垫高 2–3mm，微微上仰
- [ ] 接线全部插紧（杜邦线接触不良是本项目第一大故障源，插完逐个用手拽一下）
