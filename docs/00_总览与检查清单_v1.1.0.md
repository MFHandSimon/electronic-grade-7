# 00 · 总览与检查清单

> 面向第一次上手这套小车的同学。按 `01 → 02 → 03 → 04` 顺序做，卡住了查 `05_排障手册`。
> 所有参数、命令、坑都是实测过的，照抄即可，**不要自己改数值**。

---

## 这套东西在干什么

一台两轮差速小车，ESP32 负责「开车 + 四个方向激光测距 + 陀螺仪算朝向」，
RDK X3（跑 Ubuntu 的板子）通过串口给 ESP32 下指令、收回数据，
两者配合让小车原地转一圈，每转 30° 测一次前后左右的距离，
最后把 48 个点画成俯视图、拟合出一个矩形，用来验证场地边界。

一句话版本：**小车绕自己转一圈 → 量四面墙在哪 → 画出场地形状。**

## 你最终要交付什么

做完这一套，你们应该能拿出三样东西：

1. **一份 CSV**：`s360_xxxxxx.csv`，列是 `yaw,f,r,b,l`，12 行数据
2. **一张俯视图 PNG**：12 个方向的测距点连成的场地轮廓
3. **一句结论**：拟合出的长宽，和卷尺实测差多少

## 两个人怎么配合（60 分钟）

这套活是**两条并行线**：一个人管「硬件」，一个人管「软件」，中间有几个必须对齐的交接点。
不要两个人抢同一件事做，也不要一个人全包——60 分钟里任何一条线卡住，另一条线就是白等。

| 角色 | 负责什么 | 对应文档 |
|---|---|---|
| **A · 硬件** | 接线、机械安装、传感器垫高、上电自检、摆场地、卷尺实测 | `01`、`04` 第一节 |
| **B · 软件** | 装 Arduino IDE 和库、烧固件、RDK 串口与脚本、跑扫描、出图拟合 | `02`、`03`、`04` |

### 时间线与交接点

| 时间 | A（硬件） | B（软件） | 交接点 |
|---|---|---|---|
| 0–15 min | 按 `01` 接线，**重点做传感器垫高** | 在自己电脑上装 IDE、加 ESP32 板卡、装 Adafruit VL53L0X 库 | — |
| 15–25 min | 接线自检（逐个拽线确认插紧）、按清单逐条打勾 | 打开 `esp32_scan_field.ino` 编译，准备烧录 | **A 说「线接完了」→ B 才能开始烧** |
| 25–35 min | 看串口开机输出，判断四路是否全 OK | 烧录 + 开串口监视器，念出 `VL x OK` / `FAIL` | **四路全 `OK` 才能往下走** |
| 35–45 min | 摆场地（矩形、车放中心、离墙 ≤1m），用卷尺量真实长宽 | RDK 上装 pyserial、读串口、发 `T` 验证、发 `W/X` 让车动 | **B 说「T 能读到数」→ 进入扫描** |
| 45–55 min | 扶车/看路、记录现象 | 发 `Z` 归零、跑 `s360.py`、判断数据是否可信 | 数据里出现大量 `200–250` 或 `-1` → 停下来查 `05` |
| 55–60 min | 卷尺数据报给 B | 拷 CSV 回电脑、跑 `plot_scan.py` / `fit_rect.py`、写结论 | — |

### 三条配合纪律

1. **单点决策**：接线问题是 A 说了算，代码问题是 B 说了算，别互相指挥
2. **改硬件必须断电**：B 在烧录/跑脚本时，A 不要动线（拔插会掉串口，白烧一次）
3. **一次只改一个变量**：读数不对时，要么只调传感器角度，要么只重插那一路线，别同时改两样——
   否则不知道是哪一项起了作用

> 如果有第三个人，多出来的那位负责「记录 + 复现」：把每一轮的现象、读数、结论记下来，
> 最后整理成交付物。没有第三个人就由 A 顺手记，别事后凭记忆补。

## 上电前检查清单（打勾再上电）

- [ ] 电机两根线分别接在 **左 IN1/IN2 = GPIO2/GPIO4**、**右 IN1/IN2 = GPIO13/GPIO27**
- [ ] 四路激光的 XSHUT 分别接 **前 18 / 后 23 / 左 5 / 右 19**
- [ ] 四路激光的 SDA 都接 **GPIO22**，SCL 都接 **GPIO21**（四路并联，别接串了）
- [ ] ESP32 的 **GPIO32(RX) 接 RDK 的 TX**，**GPIO33(TX) 接 RDK 的 RX**（交叉，别接成同名）
- [ ] ESP32 和 RDK 的 **GND 连在一起**（不共地一定收不到数据）
- [ ] 每个 VL53L0X 的 **VIN 接 3.3V**（接 5V 会烧，模块不耐 5V）
- [ ] 传感器镜头侧**垫高 2–3mm**，让镜头微微**上仰**（这是本项目最关键的一步，见 `01` 最后一节）
- [ ] 车上电后先架空轮子，别让车直接冲出去

---

## 三个必须记住的结论

1. **传感器绝对不能朝下**。有 11° 左右俯角时，激光会先打到地面（约 250mm），墙面永远测不到。
2. **车必须放在场地中心附近**。放角落时对角距离接近 1.9m，超过 VL53L0X 的量程，会大量返回 `-1`。
3. **串口数据帧是 5 个字段**（`f r b l yaw`）。少解析一个，脚本会崩，车会撞墙还继续转。
