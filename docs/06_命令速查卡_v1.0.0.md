> 一页纸，放桌上用。详细说明见 `01`–`05`。

## 引脚

```
左电机  IN1=GPIO2   IN2=GPIO4
右电机  IN1=GPIO13  IN2=GPIO27
I2C     SDA=GPIO22  SCL=GPIO21
串口    RX=GPIO32(接RDK TX)  TX=GPIO33(接RDK RX)  GND↔RDK GND

激光 XSHUT：前=18(→0x30) 后=23(→0x31) 左=5(→0x32) 右=19(→0x33)
MPU6050：0x68（板载）
RDK 串口：/dev/ttyS3  115200 8N1
```

---

## 固件命令（串口发单字符）

| 命令 | 作用 | 返回 |
|---|---|---|
| `W` | 前进 | `K` |
| `S` | 后退 | `K` |
| `X` | 停止 | `K` |
| `A` | 原地左转 | `K` |
| `D` | 原地右转 | `K` |
| `Z` | 航向角归零 | `YAW:0.0` |
| `T` | 单次读四向 | `T:f r b l yaw` |
| `C` | 开流式（10Hz） | `K`，之后持续 `D:...` |
| `E` | 停流式 | `K` |
| `G` | 陀螺探针 | `GYRO: 0x68 r75=...` |

**数据帧是 5 个字段**：`T:573 982 610 845 37`
→ 前 573 / 右 982 / 后 610 / 左 845 mm，yaw = 37/10 = 3.7°
→ `-1` = 无效/超量程

## 常用命令

```bash
# 读串口 8 秒（先开监听，再按 RST）
python3 -c "
import serial,time
s=serial.Serial('/dev/ttyS3',115200,timeout=0.5)
t=time.time()
while time.time()-t<8:
    d=s.read(400)
    if d: print(d.decode(errors='ignore'),end='',flush=True)
"

# 发一条 T
python3 -c "
import serial,time
s=serial.Serial('/dev/ttyS3',115200,timeout=0.3)
time.sleep(0.2); s.reset_input_buffer()
s.write(b'T'); time.sleep(0.3)
print(s.readline().decode(errors='ignore').strip())
"

# 前进 1 秒后停（先架空！）
python3 -c "
import serial,time
s=serial.Serial('/dev/ttyS3',115200,timeout=0.2)
time.sleep(0.2)
try:
    s.write(b'W'); time.sleep(1.0)
finally:
    s.write(b'X'); s.close()
"

# 跑扫描
python3 /app/s360.py

# 出图 / 拟合（电脑上跑）
python3 plot_scan.py s360_xxxxxx.csv --png out.png
python3 fit_rect.py  s360_xxxxxx.csv --png fit.png
```

## 三条铁律

1. **传感器要微微上仰**（镜头侧垫高 2–3mm），否则全在量地面（读数 200–250）
2. **车放场地中心，离墙 ≤1m**，放角落对角落超量程（大量 `-1`）
3. **驱动脚本必须 `try/finally` 发 `X`**，否则崩了车会一直冲
