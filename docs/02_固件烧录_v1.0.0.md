# 02 · ESP32 固件烧录

> 目标：把 `esp32_scan_field/esp32_scan_field.ino`（v1.2.0）烧进 ESP32，
> 开机后能看到四路激光全部 `OK`。

---

## 一、装软件（只做一次）

### 1. 安装 Arduino IDE 2.x

下载地址：https://www.arduino.cc/en/software
装完打开，界面是黑色的新版 IDE。

### 2. 加 ESP32 板卡支持

`File → Preferences → Additional boards manager URLs` 里粘这一行：

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

然后 `Tools → Board → Boards Manager`，搜 **esp32**，装 **esp32 by Espressif Systems**。
（2.x 和 3.x 都能用，固件里两种 PWM API 都做了兼容。）

### 3. 装库

`Tools → Manage Libraries`，搜并安装：

| 库名 | 作者 | 说明 |
|---|---|---|
| **Adafruit VL53L0X** | Adafruit | 必需 |

装的时候如果提示装依赖 **Adafruit BusIO**，点「Install all」一起装。

> 陀螺仪不用额外装库，固件是直接读写 MPU6050 寄存器实现的，只要 `Wire.h`（Arduino 自带）。

---

## 二、打开工程

1. Arduino IDE → `File → Open` → 选 `esp32_scan_field/esp32_scan_field.ino`
2. 打开后 IDE 会把这个文件夹当成工程（`.ino` 名字必须和文件夹同名，**别改文件名**）

---

## 三、选板子和端口

| 设置项 | 选什么 |
|---|---|
| Board | **ESP32 Dev Module**（或 `ESP32 DevKit V1` / `esp32doit-devkit-v1`） |
| Upload Speed | 115200 |
| Flash Frequency | 40MHz |
| Flash Mode | QIO |
| Port | 插上 USB 后出现的 `COMx`（Windows）/ `/dev/ttyUSB0`（Linux） |

**找不到端口**基本是两个原因：
- 线是充电线不是数据线 → 换一根
- 没装 CP210x / CH340 驱动 → 装驱动后重插

---

## 四、编译烧录

点左上角 → 箭头（Upload）。等底部出现：

```
Writing at 0x000e0000... (100 %)
Hash of data verified.
Leaving...
Hard resetting via RTS pin...
```

就是烧好了。看内存占用的话编译完会打印类似：

```
Sketch uses 352339 bytes (26%) of program storage space.
Global variables use 24944 bytes (7%) of dynamic memory.
```

> 烧录时**车要架空**或者断电给电机，因为烧完立刻执行 `setup()`，
> 传感器初始化和电机 PWM 都会动，轮子可能突然转一下。

### 命令行烧录（可选，不用 IDE 的话）

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32doit-devkit-v1 esp32_scan_field
arduino-cli upload  --fqbn esp32:esp32:esp32doit-devkit-v1 -p COM7 esp32_scan_field
```

## 五、验证开机信息

烧完打开 `Tools → Serial Monitor`，波特率选 **115200**，按一下板上 **RST** 键，正常应该看到：

```
BUS[all_off]: 68
BUS[F_on]: 29 68
VL F OK
VL B OK
VL L OK
VL R OK
BUS[final]: 30 31 32 33 68
GYRO: 0x68 r75=68 r00=85 r0F=B0
MPU: bias=-12 n=200
READY
```

### 逐行意思

| 输出 | 含义 | 不正常怎么办 |
|---|---|---|
| `BUS[all_off]: 68` | 四路 XSHUT 全拉低时总线上只剩陀螺 | 出现 `29` → 某路 XSHUT 悬空/接错 |
| `BUS[F_on]: 29 68` | 拉高前向 XSHUT 后多出一个 0x29 | 没有 `29` → 该模块没供电或线松 |
| `VL F OK` … `VL R OK` | 四路依次改址成功 | 有 `FAIL` → 查那一路 XSHUT、SDA/SCL |
| `BUS[final]: 30 31 32 33 68` | 最终地址全在 | 缺哪个地址就是哪路没配上 |
| `GYRO: 0x68 r75=68` | 0x68 上是 MPU6050（r75 就是 WHO_AM_I） | `r75=FF` → I2C 不通 |
| `MPU: bias=xxx n=200` | 静止 200 样本零偏标定完成 | `n=0` → 陀螺读不到 |
| `READY` | 初始化全部完成，可以收指令了 | 没有 → 见 `05_排障手册` |

**四路全 OK 才往下做。** 有 FAIL 的先解决问题，别硬着头皮往下走——
失败的那一路代码会一直返回 `-1`，之后扫描数据里会满是 `-1`。

## 六、串口里手测一下

在 Serial Monitor 的输入框（底下那行）里，**先把换行设为「No line ending」**，然后：

| 输入 | 期望 |
|---|---|
| `T` | 回 `T:xxx xxx xxx xxx yaw值`（5 个数字，yaw 是角度×10） |
| `C` | 回 `K`，然后每 100ms 刷一行 `D:...` |
| `E` | 回 `K`，停止刷 |
| `W` | 回 `K`，车前进（先架空！） |
| `X` | 回 `K`，停车 |
| `A` / `D` | 回 `K`，原地左转 / 右转 |
| `Z` | 回 `YAW:0.0`，航向角归零 |

例：`T:573 982 610 845 37` → 前 573mm、右 982mm、后 610mm、左 845mm、航向 3.7°。

> 注意：单字符命令**不要带回车**，带回车会多出一个换行符，固件虽然会跳过 `\r\n`，
> 但有些串口工具会一次发 `T\r\n`，这时也能正常解析。实在不行就试「No line ending」。

## 常见烧录失败

| 报错 | 原因 | 解决 |
|---|---|---|
| `Failed to connect to ESP32: Timed out waiting for packet header` | 板子没进下载模式 | 按住板上 **BOOT** 键再点上传，看到 `Connecting...` 松手 |
| `A fatal error occurred: Could not open port COMx` | 端口被占用 | 关掉其他串口助手、Serial Monitor、Arduino 旧窗口 |
| 编译报 `Adafruit_VL53L0X.h: No such file` | 库没装 | 回第一步装库 |
| 编译报 `ledcAttach was not declared` | 用了 esp32 2.x 板卡包 | 固件已兼容，检查是否改过代码；或升级到 3.x |
| 烧完一直重启，串口反复刷 `VL F FAIL` | 前向模块没通（线松/XSHUT） | 见 `05_排障手册` 第 1 条 |
