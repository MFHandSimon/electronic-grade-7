# 00 · 总览与检查清单

> 面向第一次上手这套小车的同学。按 `01 → 02 → 03 → 04` 顺序做，卡住了查 `05_排障手册`。
> 所有参数、命令、坑都是实测过的，照抄即可，**不要自己改数值**。

---

## 这套东西在干什么

一台两轮差速小车，ESP32 负责「开车 + 四个方向激光测距 + 陀螺仪算朝向」，
RDK X3（跑 Ubuntu 的板子）通过串口给 ESP32 下指令、收回数据，
两者配合让小车原地转一圈，每转 30° 测一次前后左右的距离，
最后把 48 个点画成俯视图、拟合出一个矩形，用来验证场地边界。

一句话版本：**小车绕自己转一圈 → 量四面墙在哪 → 画出场地形状。**

## 你最终要交付什么

做完这一套，你应该能拿出三样东西：

1. **一份 CSV**：`s360_xxxxxx.csv`，列是 `yaw,f,r,b,l`，12 行数据
2. **一张俯视图 PNG**：12 个方向的测距点连成的场地轮廓
3. **一句结论**：拟合出的长宽，和卷尺实测差多少

## 上电前检查清单（打勾再上电）

- [ ] 电机两根线分别接在 **左 IN1/IN2 = GPIO2/GPIO4**、**右 IN1/IN2 = GPIO13/GPIO27**
- [ ] 四路激光的 XSHUT 分别接 **前 18 / 后 23 / 左 5 / 右 19**
- [ ] 四路激光的 SDA 都接 **GPIO22**，SCL 都接 **GPIO21**（四路并联，别接串了）
- [ ] ESP32 的 **GPIO32(RX) 接 RDK 的 TX**，**GPIO33(TX) 接 RDK 的 RX**（交叉，别接成同名）
- [ ] ESP32 和 RDK 的 **GND 连在一起**（不共地一定收不到数据）
- [ ] 每个 VL53L0X 的 **VIN 接 3.3V**（接 5V 会烧，模块不耐 5V）
- [ ] 传感器镜头侧**垫高 2–3mm**，让镜头微微**上仰**（这是本项目最关键的一步，见 `01` 最后一节）
- [ ] 车上电后先架空轮子，别让车直接冲出去

---

## 三个必须记住的结论

1. **传感器绝对不能朝下**。有 11° 左右俯角时，激光会先打到地面（约 250mm），墙面永远测不到。
2. **车必须放在场地中心附近**。放角落时对角距离接近 1.9m，超过 VL53L0X 的量程，会大量返回 `-1`。
3. **串口数据帧是 5 个字段**（`f r b l yaw`）。少解析一个，脚本会崩，车会撞墙还继续转。
